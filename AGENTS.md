# Storefront colour theme

Use the existing TwinsTech dark theme for new or updated storefront UI. Match nearby components and use the established colours for their existing roles.

| Role | Colour |
| --- | --- |
| Page background, header, and panels | `#161b22` |
| Cards and input backgrounds | `#0d1117` |
| Borders and dividers | `#21262d` |
| Primary text | `#e6e9ef` |
| Secondary text and icons | `#aab1bd` |
| Primary violet accent | `#7b5cff` |
| Primary button gradient | `linear-gradient(135deg, #7b5cff, #9d7bff)` |
| Light violet wordmark accent | `#b9a4ff` |
